# Iconography Rule

- Always use Font Awesome icons (`<i class="fa-solid fa-..." ></i>`, `<i class="fa-regular fa-..." ></i>`, `<i class="fa-brands fa-..." ></i>`) across all templates in the project.
- Do NOT use inline `<svg>` elements for icons.
- Font Awesome Free is configured in `angular.json` (`./node_modules/@fortawesome/fontawesome-free/css/all.min.css`).
